# AGENTS.md

Guidance for AI coding agents (GitHub Copilot, Claude Code, and similar tools) working in this repository.

## Instructions live in CLAUDE.md

The authoritative agent instructions for this repository are in **`CLAUDE.md`** at the repository root. Read that file and follow it in full — it covers the architecture, build and test commands, the frontend component-library rules, and the code-quality checklist.

## Local overrides (optional)

If a file named `CLAUDE.local.md` exists in the repository root, read it first and follow its instructions, treating it as taking precedence wherever it overlaps with `CLAUDE.md`. This file is optional and git-ignored: if it is absent, ignore this section.
